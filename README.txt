ARPANA & CHANDAN — WEDDING INVITATION WEBSITE

FILES
- index.html : website structure
- style.css  : all visual styles and animations
- script.js  : language switch, countdown, gallery, sound and interactions
- assets/    : generated couple illustration and the three original invitation-card photos
- music/     : original synthesized instrumental-style wedding background loop (WAV)

HOW TO OPEN
1. Extract the ZIP file completely.
2. Keep index.html, style.css, script.js, assets/, and music/ together in the same folder.
3. Double-click index.html to preview in a browser.
4. For GitHub Pages, upload all these files/folders to the repository root and enable Pages.

NOTES
- Background music starts only after the visitor taps the invitation/sound button, because browsers block autoplay.
- Google Fonts need an internet connection; the rest of the site files are included locally.
- The couple image is an AI-generated illustrative image, not a real photograph of the couple.
